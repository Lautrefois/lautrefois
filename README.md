# L'Autrefois · table page

The page customers open from the QR code on their table:
**https://shinigami63.github.io/lautrefois-table/?t=<table code>**

Menu and orders, call a waiter, cutlery, the bill, complaints and reviews. Requests go through a
Supabase "mailbox" to the café's POS computer, which rings the waiters' phones.

This repository only holds the public page (no passwords, sales or customer data). It is generated
from the POS project: do not edit these files by hand.
